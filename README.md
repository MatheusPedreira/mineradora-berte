# mineradora-berte

Site institucional da Mineradora Berté — areia, brita e agregados em Ponte Serrada (SC).

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

- Dados da empresa e catálogo: `src/content/`
- Fotografias: `public/images/` (ver `docs/BRIEFING.md`)
- Variáveis de ambiente: `.env.example` (sem domínio configurado o site fica em `noindex`)
- Briefing, pendências e decisões: `docs/BRIEFING.md`
